Methodological Evaluation Caveat: Baseline validation metrics (98.3% mAP@50) are in-distribution indicators and may be optimistic because temporally adjacent video frames were split across training and validation sets. 🔍 Failure Mode Investigation & Mitigation Flow

Vertical root-cause anatomy: Observed Failure → Root Cause Hypothesis → Empirical Evidence → Engineering Mitigation → Post-Mitigation Result & Scope

FAILURE 01 // FALSE ACTIVATION White Surface False Positive Proposal
Suppressed on Test Image
Observed Failure

74.5% confidence false detection on an unannotated neutral whiteboard test surface.

Root Cause Hypothesis

Absence of negative-only (background) images in the baseline training set caused the detector to over-index on white boundary contrast.

Empirical Evidence

0% negative-image coverage in original dataset audit (all 43 images contained foreground bottles).

Engineering Mitigation

Integrated 138 hard-negative background tiles (plant floor, wall, drain, neutral frames) with empty labels into a 15-epoch calibration fine-tuning pass.

Observed Result & Scope

0 detections observed on evaluated whiteboard test image.
Scope: Single controlled test condition — not a universal FP claim

FAILURE 02 // GEOMETRIC ARTIFACT Conveyor Frame & Metallic Rail Ghost Proposals
Suppressed at Operating Threshold
Observed Failure

Ghost detections on empty conveyor lower rails, motor mounts, and drain grates when operating at low confidence (< 0.35).

Root Cause Hypothesis

Parallel linear metallic slots and cylindrical rail curvature share gradient and aspect ratio features with bottle silhouettes.

Empirical Evidence

Persistent false activations observed on empty plant background crops during calibration review.

Engineering Mitigation

Enforced operational confidence threshold (≥ 0.40) and paired 38 empty conveyor, guide rail, and drain grate negative tiles.

Observed Result & Scope

False activations suppressed at operational threshold in evaluated calibration samples.
Scope: Evaluated calibration set

FAILURE 03 // SPECULAR ARTIFACT Stainless Steel Plate Specular Highlight Glare
Reduced in Calibration Set
Observed Failure

Intermittent false proposals triggered by overhead fluorescent fixtures mirroring bottle reflections on stainless steel bed plates.

Root Cause Hypothesis

High-intensity specular hotspots generate high-frequency boundary gradients mimicking bottle neck and cap highlights.

Empirical Evidence

Confidence spikes coinciding with fluctuating plant lighting conditions on reflective metal surfaces.

Engineering Mitigation

Added unannotated reflective steel plate tiles and brightness/contrast jitter augmentations during calibration fine-tune.

Observed Result & Scope

Specular false proposals reduced in evaluated calibration samples.
Scope: Factory lighting remains an external environmental variable

FAILURE 04 // DATASET CONTAMINATION Temporal Train-Validation Frame Autocorrelation
Identified & Documented
Observed Failure

Disparity between high baseline validation metrics (98.3% mAP@50) and real-world edge case false positive susceptibility.

Root Cause Hypothesis

Random frame-level splitting on continuous video captures caused near-identical adjacent frames to populate both train and validation splits.

Empirical Evidence

Inspection revealed temporally adjacent frames (frame t and frame t+1) divided across training and validation partitions.

Engineering Mitigation

Designed a sequence-aware validation protocol partitioning by distinct recording episodes, and established a dedicated hard-negative evaluation suite.

Observed Result & Scope

Temporal leakage isolated and documented; baseline metrics scoped as in-distribution indicators.
Scope: Dataset architecture audit and protocol design

FAILURE 05 // TEMPORAL CONTINUITY Transient Detection Dropout & Track ID Fragmentation
Test Suite Verified
Observed Failure

Momentary confidence dips during bottle clustering, minor motion blur, or partial occlusion risking track ID loss or duplicate counting.

Root Cause Hypothesis

Single-threshold association discards valid detections when confidence drops marginally below the primary threshold.

Empirical Evidence

Transient single-frame dropouts observed in continuous video footage during conveyor belt speed surges.

Engineering Mitigation

Implemented ByteTrack two-stage association (matching high-confidence detections first, then associating low-confidence [0.10–0.40] detections with existing tracks) with Kalman motion filtering.

Observed Result & Scope

No ID swap observed in deterministic two-object test; track continuity maintained across 3-frame occlusion dropouts.
Scope: Automated test suite (tests/test_tracker.py, tests/test_counter.py)

EXPERIMENTAL DELTA ANALYSIS // ENGINEERING RATIONALE
Why Recall Dropped (96.6% → 84.2%): Calibration penalized false positive activations across 138 background tiles. The model learned more conservative boundary decision thresholds, trading off edge-case sensitivity for false-positive suppression.
Why mAP@50-95 Rose (63.9% → 79.1%): An absolute gain of +15.24 percentage points (+23.85% relative) demonstrates significantly tighter bounding-box localization on the controlled calibration split.
Methodological Context: Evaluation protocols differ between the original random frame split and the controlled calibration split. These figures serve as diagnostic evidence of mitigation rather than a direct replacement benchmark.
